# Experiment 6 - Semaphore Implementation

## Aim

To implement Mutual Exclusion using Semaphore.

## Objectives

- Study the concept of Semaphores.
- Understand Mutual Exclusion.
- Synchronize Parent and Child Processes.
- Prevent race conditions using Semaphores.

## Programs Included

1. Semaphore Implementation (C Program)
2. Semaphore Simulation (Shell Script)

## Software Requirements

- Kali Linux
- GCC Compiler
- Bash Shell

## Compile and Run

Compile the C program:

```bash
gcc semaphore.c -o semaphore -pthread
./semaphore
```

Run the shell script:

```bash
chmod +x semaphore.sh
./semaphore.sh
```

## Result

Thus, Mutual Exclusion using Semaphore was implemented successfully.
