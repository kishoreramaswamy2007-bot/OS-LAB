# Experiment 5 - Inter Process Communication (IPC)

## Aim

To study and implement Inter Process Communication (IPC) using Pipe Mechanism in UNIX.

## Objectives

- Study the concept of Inter Process Communication (IPC).
- Understand communication between parent and child processes.
- Implement IPC using Pipes.
- Execute IPC programs using C programming and Shell scripting.

## Programs Included

1. IPC using Pipe (C Program)
2. IPC using Pipe (Shell Script)

## Software Requirements

- Kali Linux
- GCC Compiler
- Bash Shell

## Compile and Run

Compile the C program:

```bash
gcc ipc_pipe.c -o ipc
./ipc
```

Run the shell script:

```bash
chmod +x ipc_pipe.sh
./ipc_pipe.sh
```

## Result

Thus, Inter Process Communication using Pipe Mechanism was implemented successfully.
